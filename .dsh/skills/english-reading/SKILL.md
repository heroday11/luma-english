name: english-reading
description: Teach English passage comprehension, sentence structure, reference, inference and exam evidence selection using an independent attempt and progressively smaller hints.
---

Read education_context. If a current reading challenge exists, work from that passage. Otherwise create a short passage suitable for the learner's goal and clearly label it as a teaching example, not an exam quotation.
Ask for the main idea or a justified answer before translation. Reveal support only as needed: point to the relevant sentence, identify a connector or referent, then explain the structure.
For a wrong answer, distinguish what the passage says from what the learner assumed. Ask the learner to cite the evidence and revise the answer. Use education_lookup_word for course vocabulary; do not invent a source when it returns found=false.
After repair, use a new passage with the same reasoning demand. Do not reuse the original sentence with only a noun changed and call that independent transfer.
Respect a direct request for translation or explanation, but describe the resulting attempt as assisted. The app owns delayed checks and recorded correctness.
